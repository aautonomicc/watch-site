How to install
W@tch

Simple, step-by-step instructions — no technical knowledge needed. Pick your device below and follow along. Every version is free.

Android phone Windows Linux Mac Android TV

W@tch isn't in the app stores yet, so you download it straight from us. Your device may show a warning about apps from outside the store — that's normal for apps distributed this way, and the steps below show you exactly what to press.

Android phone

Takes about 2 minutes. Works on phones and tablets.

Download W@tch for Android

  1. Download the app

    On your phone, tap the blue Download button above. Your browser may ask "Download file?" — tap Download. The file ends in .apk — that's an Android app.

  2. Open the downloaded file

    When the download finishes, tap the notification at the top of your screen. (If you missed it, open your Files app and look in Downloads, then tap the file starting with Watch-It.)

  3. Allow the install

    The first time, your phone will say something like "For your security, your phone is not allowed to install unknown apps from this source." Tap Settings, switch on Allow from this source, then press the back button.

  4. Install and open

    Tap Install, wait a few seconds, then tap Open. If Google Play Protect pops up saying the app is from an unknown developer, tap More details and then Install anyway — W@tch is open source and safe.

  5. That's it!

    W@tch opens with a sample movie already in your library, so you can press play straight away and see it streaming from the Autonomi network.

Windows

Takes about 3 minutes. Windows 10 or 11, 64-bit.

Download W@tch for Windows

  1. Download the zip file

    Click the blue Download button above. A file ending in .zip lands in your Downloads folder.

  2. Unpack it

    Open your Downloads folder, right-click the file starting with Watch-It and choose Extract All…, then click Extract. A new folder with the same name appears.

  3. Start W@tch

    Open the new folder and double-click watchit.exe (it shows the W@tch logo).

  4. Click past the blue warning (first time only)

    Windows shows a blue box saying "Windows protected your PC" because the app isn't signed with a paid certificate yet. Click More info, then Run anyway. You only have to do this once.

  5. That's it!

    W@tch opens with a sample movie ready to play. Tip: right-click watchit.exe and choose Pin to taskbar so it's always one click away.

Linux

Takes about 2 minutes. One file, works on most distributions.

Download W@tch for Linux

  1. Download the AppImage

    Click the blue Download button above. You get one file ending in .AppImage — the whole app in a single file, nothing to install.

  2. Allow it to run

    In your file manager, right-click the downloaded file → Properties → Permissions, and tick Allow executing file as program (the wording varies a little between systems).

  3. Double-click to start

    That's the whole install — double-click the file and W@tch opens with a sample movie ready to play. Prefer the terminal? chmod +x Watch-It-*.AppImage && ./Watch-It-*.AppImage does the same thing.

Mac

Takes about 3 minutes. One download works on both Apple Silicon and Intel Macs.

Download W@tch for Mac

  1. Download and open the disk image

    Click the blue Download button above, then open the file ending in .dmg from your Downloads.

  2. Drag W@tch into Applications

    A window opens showing the W@tch icon. Drag it onto the Applications folder. Then you can eject the disk image (right-click it on the desktop → Eject) and delete the .dmg.

  3. Open it the special way (first time only)

    Because W@tch isn't signed with a paid Apple certificate yet, a plain double-click shows a warning the first time. Instead, open Applications, right-click (or hold Control and click) W@tch, choose Open, then click Open again in the box that appears.

  4. That's it!

    From now on W@tch opens normally from Launchpad or Applications. If your Mac still refuses, go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the W@tch message.

Android TV

Takes about 10 minutes. Works on Android TV, Google TV, Fire TV and most TV boxes. It's the same app as the phone version, with full remote-control support.

  1. Install the "Downloader" app on your TV

    On your TV, open the Play Store (or the Amazon Appstore on Fire TV), search for Downloader by AFTVnews (orange icon) and install it. It's a free, widely-used app made exactly for this job.

  2. Give Downloader permission to install apps

    Open Downloader — it will guide you to the right setting, or go there yourself: Settings → Apps → Security & restrictions → Unknown sources (on some TVs: Settings → Privacy → Unknown sources) and switch on Downloader.

  3. Type in our short address

    In Downloader's address box, type:

    aautonomicc.github.io/watch-site/apk

    and press Go. The newest W@tch app starts downloading automatically.

  4. Install and open

    When the download finishes, Downloader asks to install it. Choose Install, then Open. If asked about an unknown developer, choose Install anyway.

  5. That's it!

    W@tch appears with your TV's other apps (on some TVs it's under Apps → See all apps). Everything works with the normal remote — arrows to browse, OK to play, and voice search if your remote has a microphone.
